1. SCREEN RECORDING (attached)
Part A, physical iPhone, latest iOS: launch, location prompt, recording, lock screen, Auto-Start. Part B: CarPlay in a real car. Part C, labeled "Simulator, sample data": list, details, map, import, so no private rides are shown. Personal totals at launch are covered. There is no registration, login or account to delete, no user-generated content shared with others and no paid content.

2. PURPOSE AND AUDIENCE
Free logbook for bicycle, e-bike, motorcycle and car rides, for people who want their own route, charts and totals without an account. No ads, tracking, user content shared in the app or purchases.

3. HOW TO USE IT
No login or demo account needed.
- Overview shows a sample ride until a ride exists. To fill Rides and Map, import this anonymized file: https://github.com/hops-1/wattspur/raw/main/App/SampleRide.fit (save to Files, then Rides > Import Files).
- Record (iPhone): Overview > Start Ride, allow location "While Using the App" and Motion & Fitness. Move a few hundred meters, Stop, Save. The name is suggested from the start and end towns.
- Background location (2.5.4): only during a recording or "Ready" that the user started or set up, so the track continues with the screen locked. A Live Activity and the system indicator show it. Stop or Cancel ends it. "Always" is never requested.
- Auto-Start (off by default): More > Recording. The user creates a Shortcuts automation (CarPlay or Bluetooth connects > Start Ride). It opens the app as "Ready"; recording begins above 10 km/h, so walking will not trigger it. It ends on disconnect (second automation, End Ride) or after standing still. Notifications only report a saved ride.
- CarPlay Driving Task (entitlement granted by Apple): allow location on the iPhone first. Start, Pause/Resume, End with confirmation, vehicle list, and one panel (speed, time, distance, lateral acceleration or lean angle) updated at most every 5 s. Apple templates only, no map, ride list or text input. Same recording as on iPhone.
- iPad: view, import, analyze, compare. No recording or CarPlay.
- Widget: This Week, Home Screen.
- iCloud: More > iCloud & Library. Sync to the user's private CloudKit database is on by default and can be turned off.
- If "Test Tools" appears under More, that is a diagnostic page for sandbox builds (TestFlight). App Store installs hide it.

4. EXTERNAL SERVICES
- Apple: MapKit, Core Location, Core Motion (barometer, lean, acceleration), CloudKit, ActivityKit, WidgetKit, App Intents. For the suggested name only the start and end point go to MapKit reverse geocoding.
- Optional map styles (More > Maps; default is Apple): OpenStreetMap, CyclOSM (OpenStreetMap France), OpenTopoMap.
- No own server, analytics, login, payment or AI service. The developer receives no data.

5. REGIONAL DIFFERENCES
None. English and German. Distances and speeds are always in km and km/h.
