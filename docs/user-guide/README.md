# Wattspur User Guide · Benutzerhandbuch

Wattspur analyses the rides you export from the Bosch eBike Flow app, locally on your Mac.
Wattspur wertet die Fahrten aus, die du aus der Bosch eBike Flow App exportierst, lokal auf deinem Mac.
